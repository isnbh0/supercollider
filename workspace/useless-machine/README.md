# Useless Machine (무용지물)

SuperCollider 기반 라이브 코딩 퍼포먼스 시스템. "자율 카오스 엔진" WILDCARD가 백그라운드에서 오디오 합성 파라미터를 무작위로 변이시켜 예측 불가능한 극적 음악 변화를 만들어냅니다.

## 컨셉

Claude Shannon의 "Ultimate Machine" (1952)에서 영감을 받았습니다. Shannon의 기계는 스위치를 켜면 상자 안에서 손이 나와 스스로 스위치를 끄는, 자기 자신을 무효화하는 장치였습니다.

이 프로젝트는 그 개념을 사운드 퍼포먼스로 확장합니다. 퍼포머가 오디오를 제어하려 할 때, WILDCARD 엔진이 개입하여 파라미터를 변이시키고, 샘플을 전환하며, 예기치 않은 폭발과 침묵을 만들어냅니다. 퍼포머와 기계 사이의 통제권 싸움이 퍼포먼스의 핵심 긴장입니다.

퍼포먼스는 미묘한 변화에서 시작해 점진적으로 완전한 카오스로 에스컬레이션되며, 최종적으로 의도적인 서버 과부하로 "붕괴"합니다 — 기계가 스스로를 파괴하는 것으로 끝납니다.

## 빠른 시작

SC IDE에서 `soundtest.scd` 파일을 열고 순서대로 실행:

```supercollider
// 1. 서버 부팅 및 샘플 로드
~boot.();

// 2. 제너레이터 설정
~prep.();

// 3. 재생 시작
~start.();

// 4. 카오스 엔진 로드 및 시작
(Document.current.dir ++ "/wildcard.scd").load;
~wildcardStart.();
```

## WILDCARD 컨트롤

```supercollider
~wildcardStart.();           // 카오스 시작 (상태 자동 저장)
~wildcardStop.();            // 카오스 정지
~wildcardSetLevel.(3);       // 카오스 레벨 설정 (1-5)
~wildcardCoda.();            // 30초 최종 붕괴 시퀀스
~wildcardRecover.();         // 긴급 정지 + 상태 복원
```

### 카오스 레벨

| 레벨 | 이름 | 설명 |
|------|------|------|
| 1 | 미묘함 | 지터만, 느린 변이 |
| 2 | 눈에 띔 | 스터터 추가 |
| 3 | 방해 | 샘플 전환 추가 |
| 4 | 혼돈 | 폭발/침묵 임팩트 추가 |
| 5 | 완전한 카오스 | 모든 변이 + 글리치 모드 |

### 변이 유형

- **STUTTER (스터터)**: 높은 확률 + 짧은 지속시간으로 급격한 리듬 변화
- **JITTER (지터)**: 시작점 랜덤화로 불안정한 재생
- **SAMPLE (샘플)**: 다른 샘플로 예고 없이 전환
- **IMPACT (임팩트)**: 모든 제너레이터 폭발 또는 갑작스러운 침묵
- **GLITCH (글리치)**: 글리치 모드 강제 활성화

## 7분 자동 퍼포먼스

전체 에스컬레이션 아크를 자동으로 실행:

```supercollider
~performanceStart.();
```

타임라인:
- 0:00 - 1:00: 레벨 1 (미묘함)
- 1:00 - 2:30: 레벨 2 (눈에 띔)
- 2:30 - 4:00: 레벨 3 (방해)
- 4:00 - 5:30: 레벨 4 (혼돈)
- 5:30 - 6:30: 레벨 5 (완전한 카오스)
- 6:30 - 7:00: CODA (붕괴 + 크래시)

## 아키텍처

```
soundtest.scd    코어 오디오 엔진
                 - 4개 제너레이터 (확률/지속시간/진폭)
                 - 샘플 기반 재생, 지터/스피드 제어
                 - 상태 스냅샷/복원 시스템

wildcard.scd     자율 카오스 엔진
                 - 5가지 변이 유형
                 - 5단계 카오스 레벨
                 - 코다: 30초 붕괴 시퀀스
                 - 연극적 출력: ASCII 아트, Zalgo 글리치 텍스트

glitch-loader.scd   샘플 로딩 모듈
```

## 비상 복구

```supercollider
// 패닉 레벨 1: 재생 정지
~stop.();
~wildcardStop.();

// 패닉 레벨 2: 상태 복원 후 재시작
~wildcardRecover.();
~stop.();
~start.();

// 패닉 레벨 3: 완전 재부팅
// Cmd+. (모든 소리 정지)
~boot.();
~prep.();
~start.();

// 즉각적인 침묵
s.freeAll;
```
